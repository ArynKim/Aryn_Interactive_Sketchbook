mid-century modern

02/14/2024

a visual guide to mid-century modern style

Reflection -- I liked the challenge this assignment presented of copying an already existing design as best I can. Looking back at the work I've done, I don't think it's too bad. I learned how organized CSS can be; I enjoy the layout a lot more than HTML, but I understand that CSS is just built around HTML and HTML is the framework that CSS works on. The biggest thing that stood out to me from this is how specific you have to be in labeling each part of CSS. I really liked that as it kept each thing organized, although it did take numerous attempts to figure out why my CSS code wasn't showing up; the solution was always just to be more specific. It was a big relief whenever I got my text to be the correct color, size, and spacing. My favorite of my work was probably getting the bottom tags to be correct! My main issue I had with this assignment was the images not loading; I couldn't exactly do anything about the images except add alt text since I can't even see the results of what I'm coding. This seems to be a persisting issue on my end for some reason. Additionally, I also struggled with the side and bottom bars. I almost didn't include the orange bars because I just couldn't figure them out, so I did the best I could which was adding a giant left and right border. It looks very off when resizing the window, but I did the best I could. What bothers me the most is how the sides and bottom don't reach the edges of the page all the way. Another issue I ran into was spacing the text; I wasn't exactly sure what the best way would be for spacing the text, especially the top text. Despite those main issues, I'm quite happy with how it turned out!
